# Fixonic Solutions

Modern Next.js web application for [Fixonic Solutions](https://www.fixonicsolutions.com) — digital agency specializing in Web Development, SEO, Digital Marketing, UI/UX Design, AI Automation, and Domain & Hosting.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **UI & Styling**: React 19, Tailwind CSS v4
- **Animation & UX**: Framer Motion, Lenis Smooth Scroll
- **Email Service**: Resend API
- **Language**: TypeScript

## Getting Started

First, install dependencies:

```bash
npm install
```

Set up your `.env.local` file:

```env
RESEND_API_KEY=your_resend_api_key
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build & Production

To create a production build:

```bash
npm run build
```

To start the production server:

```bash
npm run start
```
